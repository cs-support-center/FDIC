# FDIC
# Modern Support Center & Live Chat Interface

A responsive, lightweight customer support portal template featuring an interactive FAQ section, structured topic navigation, and seamless live chat integration.

## Features

- **Responsive Design:** Fully mobile-friendly layout optimized for desktop, tablet, and mobile screens.
- **Interactive FAQ Accordion:** Clean dropdown answers built using native HTML `<details>` and `<summary>` elements.
- **Structured Categories:** Modern multi-column layout for browsing support topics and help articles.
- **Live Chat Integration:** Pre-configured triggers to launch live chat widgets dynamically.
- **Clean Styling:** Organized CSS using custom CSS variables for easy color theme customization.
